危険な操作

{{if not $c.IsPublic}}

Client Secret を再発行する。新しいシークレットを生成し、旧シークレットを直ちに無効にする（Client.RotateSecret、Store.RotateClientSecret）。新旧を併用する期間はないので、Client 側の設定を差し替えるまで、トークンエンドポイントへの要求は invalid_client になる。発行済みのトークンと Grant はそのまま残る。漏えいへの対応なら、上の一覧から連携の解除も検討する。

{{end}}

この Client を削除する。同じ操作で、この Client の全 Grant と配下の Token Family・トークンが失効し、Authorization Code も消える（Store.DeleteClient）。元に戻せない。同じ client_id で作り直しても、ユーザーは同意をやり直す。
